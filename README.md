# EveryFigureCalc

Free online calculators for time, work hours, pay, money and everyday math.

- **Site:** [everyfigurecalc.com](https://everyfigurecalc.com)
- **Stack:** React, TanStack Start, Tailwind CSS, Cloudflare Workers

## Development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

Deploy the `.output` folder to Cloudflare Pages/Workers.

Set this environment variable for production:

```
VITE_SITE_URL=https://everyfigurecalc.com
```
